# RCVB V1.0 Render 在线演示

基于 RC 热模型与室内热舒适约束的建筑虚拟储能柔性调控研究平台。

- 24 个 D0 场景先验与 24h 实验流程
- 1 分钟 CSV 上传、5/15 分钟等效参数辨识
- `RC`、`R×η`、`C/η` 及质量门控
- 已验证合成日的联合 MPC 对照结果
- 无 EMS/BMS 写接口，不允许直接接管现场设备

本公网版的联合 MPC 页面展示保存的验证算例，不在免费实例上重新执行 MILP；CSV 参数辨识由后端实时计算。

## 滚动 MPC 动态回放

在“示范结果”的展示方案中选择“滚动MPC模拟”，点击“播放”。支持暂停、重新开始、逐步查看、进度定位、0.5/1/2/4 倍速和循环播放。默认约 48 秒播放一天，日末停留 2 秒后循环；离开结果页或切换到浏览器后台会暂停。

五张图共享当前时刻，浅蓝色带仅示意未来 4 小时窗口，不代表保存了未来预测轨迹。曲线、状态栏和区间平均功率按同一时间对齐；全天费用及对照表保持全天统计口径。回放不触发求解、不发送设备指令，也不会修改导出的原始算例数据。

回放逻辑检查（需 Node.js）：`node --test test_replay.cjs`。
